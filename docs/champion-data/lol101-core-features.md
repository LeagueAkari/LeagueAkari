# LOL101 核心查阅功能

本次基于四层数据边界补齐核心查阅流程，不提供推荐应用或自动修改游戏配置。

## 能力变化

| 原有能力                                 | 本次补齐                                                                                 |
| ---------------------------------------- | ---------------------------------------------------------------------------------------- |
| 峡谷、极地、经典、海克斯英雄/强化/拍档榜 | 榜单保留搜索和排序，加入反制英雄、热度、适配英雄、独立统计日期和经典分路信息             |
| 已有峡谷详情接口，但没有可用页面         | 符文、技能、加点、各阶段出装、对线、搭档、分路、趋势、段位、时长全部可查                 |
| 已有打野路线解析                         | 蓝红方和起点筛选，野怪顺序、样本量、选择率与胜率                                         |
| 已有海克斯英雄推荐接口                   | 英雄概况、强化推荐/品质分组/搜索、出装、加点与搭档                                       |
| 只有全局拍档榜                           | 独立拍档查询页，按英雄及两个职业条件请求官方接口                                         |
| 只有一份英雄选择状态                     | 通用页面联合：英雄页、拍档页；标签独立查询、刷新、关闭、排序、关闭其他页面，相同查询复用 |
| 符文/装备/召唤师技能依赖 LCU 资源        | 官网资源目录兜底，未连接客户端仍可显示名称、图标和说明                                   |

## 页面与组件

榜单标签常驻。英雄关联点击打开或复用详情标签，拍档查询使用独立标签。各标签保留自己的模式、版本、段位、分路或拍档条件；改变榜单不重置已打开页面。标签仅保存在窗口会话中。

OP.GG 与 LOL101 共用 TabBar、QuerySelect/FilterLabel、RunePageDisplay、SettingsSection、ExpandButton，以及既有装备/技能/强化提示组件。列表先显示主要推荐，可展开查看全部。删除右上角总刷新及详情返回按钮；标签刷新负责整页，失败分区提供局部重试。

页面以 `kind` 区分，英雄查询与详情以 `mode` 区分。各分区使用 `status` 判别联合表达 idle/loading/ready/empty/error。旧单英雄详情加载流程和状态已删除。

## 请求与数据约定

- 全部 QQ101 统计请求共用四并发队列，多个后台标签不会各自放大请求上限。
- 标签独立拥有取消信号。关闭、刷新、改变该页条件会取消旧请求；切换激活标签保留后台加载和结果。
- 从榜单行进入使用该行分路，其他入口先解析可用分路；无榜单记录仍可请求英雄详情。
- 对线第三列为胜率，第四列为带符号的收益率，分别保留；`-1` 对收益率是合法数值。
- 英雄专属强化推荐与全局强化统计分开；品质查询使用上游对应分组。
- 加点保持上游长度和顺序，不推断补齐到十八级。特殊英雄的加点提示说明属性加点语义。
- 拍档筛选参数实测支持 `role1=tank`、`role2=mage` 和具体 `championid`；排名按当前上游查询返回值展示，不自行重编号。
- 资源缺项保留原始 ID 和统计，模式装备 ID 不转换为普通装备 ID。GTIMG 目录字段经过 Zod 校验及诊断，未使用字段剔除。

## 边界

- 官网当前极地、经典榜单不提供同类构筑详情，因此没有伪造详情页面。
- 全局拍档结果有数量上限；指定英雄/职业通过服务端查询，不在全局有限结果中冒充完整筛选。
- 各接口更新日期可能不同。每日英雄榜保留请求快照日期；详情、强化和拍档保留各自响应日期。
- 官网目录目前以中文为主；界面文案支持中英文，目录内容不伪造翻译。
- 未引入资讯、背景故事、独立百科、版本研究、账号或游戏配置写入。

## 验证结果（2026-10-07）

- 类型检查、112 个测试文件 / 713 项测试、生产构建通过。构建仍提示大分块体积警告。
- Electron 实测：峡谷详情、打野路线、海克斯详情、英雄/职业拍档查询、多标签独立版本和段位、资源缺失时保留统计。
- 回归覆盖关闭页面后的迟到响应、分区失败重试、分路失败恢复、全局四并发、无效记录隔离、带符号收益率及描述转义。
- 详情滚动使用 NScrollbar；样本量使用千分位。当前官网适应之力描述经转换后为“+9 适应之力”，不再显示转义的 League UI 标签或属性。
- GTIMG 资源统一受 `extra-assets.gtimg` 控制，未配置时默认开启。关闭会取消资源请求、清空目录并屏蔽 GTIMG 图片；数据经过 schema 校验，损坏条目降级并记录日志。此开关不控制 101 统计接口。
- 未连接客户端时，符文、装备、召唤师技能来自腾讯 GTIMG 官网目录；优先使用可用 LCU 资源，目录为兜底。
