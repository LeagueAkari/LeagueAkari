# Champion Data 数据边界

直接信任 OP.GG、QQ101 和配套腾讯目录的响应。手写 TypeScript 类型描述约定，关键协议注释标注最后实测日期；没有运行时 schema、字段恢复、坏记录过滤或解析诊断层。

## 请求与转换

| 层                | 职责                                                            | 实现                                             |
| ----------------- | --------------------------------------------------------------- | ------------------------------------------------ |
| HTTP              | 组装 URL、参数、AbortSignal，返回带接口类型的原始响应           | `src/shared/http-api-axios-helper/{opgg,qq101}/` |
| QQ101 adapter     | 一次性解开内嵌 JSON、分隔记录和数值编码，输出驼峰字段及业务单位 | `src/shared/data-adapter/qq101/protocol.ts`      |
| QQ101 data source | 调度请求并调用 adapter，只向业务暴露 Akari 对象                 | `src/shared/data-sources/qq101/`                 |
| OP.GG projection  | 将普通 JSON 投影为页面展示模型                                  | `src/shared/data-adapter/opgg/projection.ts`     |

QQ101 的 `Rxxxxx`、原始字段和分隔符不进入 loader、controller 或页面。例如 `52.16` 直接转换成 `winRate: 0.5216`。协议约定的空载荷、`NC` 比较值、`255` 汇总分类属于正常数据语义，转换时按其含义处理。

OP.GG 的原始类型位于 `src/shared/types/opgg/`，QQ101 位于 `src/shared/types/qq101.ts`。腾讯目录的类型位于 `src/shared/data-sources/gtimg/responses.ts`。以上约定最后实测于 **2026-11-15**。

## 失败与空数据

格式变更造成的解码或投影异常沿用请求错误状态，用户可以重试。不猜测其他载荷字段，不补造统计或身份，不跳过坏行，也不切换来源、旧版本或旧日期来替代当前结果。

QQ101 日榜请求中国时区的前一日快照，未发布时展示空数据。最新排位版本无数据时保持该版本。各独立请求的网络失败、取消和单独重试仍由原有 loader/controller 管理。

推荐应用直接使用来源给出的第一套推荐，不再做字段校验或寻找另一套“有效”配置。窗口状态、模式支持、手动接管和过期任务取消仍属于业务调度。

保留正常业务转换：统计比例、经典服英雄 ID、可购买装备配方，以及描述文本到页面支持标签的转换。HTML 展示仍不转发远端可执行属性。

## 业务类型与验证

OP.GG 详情按 `kind` 区分常规模式、Arena、Mayhem；QQ101 按 `mode` 区分。业务读取已转换对象，不理解传输协议。`null` 和可选字段只表示接口或业务明确允许的缺失。

测试覆盖实际协议转换、业务结果、请求取消及版本隔离。删除仅为恢复异常结构而存在的测试，不以源码字符串检查实现。
